A fast & powerful Android launcher/search app that lets you search across apps, app shortcuts, contacts, calendar events, device files, device settings, app settings, and the web, plus access tools like calculator, unit converter, and AI search—all from a single search bar. Built with Kotlin and Jetpack Compose using Material 3 design.

### Key Features

* **Apps**: Search and launch installed applications with smart ranking. App search ignores typos and allows abbreviations.
* **All Apps View**: Browse all installed apps in a grid, with a quick "Show All Apps" toggle.
* **Contacts**: Find and call/text contacts with multi-number support and integrations.
* **Calendar Events**: Search your calendar events from the search bar.
* **Files**: Search device files and folders.
* **Device & App Settings**: Search Android system settings and Quick Search Pro settings.
* **Top Matches**: Turn this on to see the top result for your query across all categories.
* **Web**: Search the web using 25 search engines with customizable shortcuts.
* **Built-in Tools**: Calculator, unit converter, currency converter, world clock, and date/time calculator.
* **AI Search**: Get AI-powered answers using models of your choice (requires your own API key).
* **Overlay Mode**: Make the search bar appear over other apps, anywhere.
* **Widgets**: Home screen search widget and custom buttons widget.

### Privacy First
Quick Search Pro prioritizes your privacy. All permissions are optional, only used to unlock additional features. All search processing happens locally on your device.

* No ads or analytics
* Encrypted storage for API keys
* Granular permission controls
* Local data processing

Based on the original Quick Search app by Teja Karlapudi.
